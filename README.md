# 풀이노트 (study-app)

필기 중심 학습관리 앱. 학생이 태블릿에 S펜으로 직접 풀고, 답을 쓰면 자동으로 채점되고, 틀린 문제는 오답노트와 복습 일정에 쌓이며, 변형문제로 다시 연습합니다. 선생님은 PC 브라우저로 학생 필기를 실시간으로 볼 수 있어요.

- 1차 대상: **갤럭시탭 S9 Ultra (Android)** — 이후 같은 코드로 iPad 빌드 예정
- 기술: Flutter (앱), Node.js (실시간 서버 + 선생님 웹)

## 설치 (태블릿)

1. 태블릿 브라우저에서 **https://github.com/BruceKalifa/study-app/releases/latest** 를 엽니다.
2. `pulinote.apk` 를 내려받아 실행합니다. 처음이면 "출처를 알 수 없는 앱 설치 허용"을 켜 주세요.
3. 코드를 고칠 때마다 GitHub Actions가 새 APK를 자동으로 만들어 같은 주소에 올립니다. 같은 서명 키를 쓰므로 **덮어서 설치**하면 기록이 유지돼요.

## 기능

### 필기 (굿노트·삼성노트 스타일)
| 동작 | 방법 |
|---|---|
| 쓰기 | S펜 (필압 반영, 저지연 입력) |
| 지우개 | **S펜 옆 버튼을 누른 채 쓰기** → 떼면 원래 펜으로 복귀. 도구막대의 지우개(획/부분)도 있음 |
| 화면 이동 / 확대 | 손가락 한 개로 이동, 두 개로 핀치 확대 (관성 스크롤) |
| 실행 취소 / 다시 실행 | 두 손가락 탭 / 세 손가락 탭 (도구막대 버튼도 있음) |
| 손바닥 인식 방지 | S펜이 닿아 있거나 화면 위에 떠 있으면 손 터치를 무시 |
| 직선 | 선을 긋고 잠깐 멈추면 반듯한 직선으로 변환 |
| 올가미 | 필기를 둘러싸서 선택 → 끌어서 이동, 복제, 색 변경, 삭제 |
| 형광펜 | 반투명, 글씨 아래에 깔림 |
| 종이 | 무지 / 줄 / 모눈 / 점 |

### 문제 풀이와 채점
- 문제는 종이처럼 화면에 인쇄되고, 그 위·아래에 바로 풀이를 씁니다. 풀다 나가도 필기는 자동 저장돼요.
- 객관식: 오른쪽 패널에서 번호 선택 → 채점
- 단답형: **손글씨로 답을 쓰면 기기 안에서 인식**(Google ML Kit, 처음 한 번 모델 약 20MB 다운로드) → 후보 선택 또는 키패드로 수정 → 채점. 분수 `-3/2`, 소수, `2√3`, `π`, 단위 붙여 쓰기 모두 허용
- 정답/오답 즉시 표시, 해설, 힌트, 북마크, 문제별 풀이 시간

### 기록과 복습 (계속 업데이트됨)
- **오답노트**: 틀린 문제가 자동으로 모이고 1일 → 3일 → 7일 간격으로 다시 나옵니다. 3번 연속 맞히면 "졸업"
- **변형문제**: 숫자·조건을 바꾼 새 문제를 무제한 생성(정답 자동 계산). 틀린 문제를 변형으로 복습
- **오늘의 학습**: 복습할 오답 + 안 푼 문제를 과목별로 섞어 하루 목표만큼 출제
- **통계**: 정답률, 연속 학습일, 최근 14일 그래프, 학습 달력, 과목·단원·난이도별 성취도, 약한 유형
- **풀이 기록**: 모든 제출 기록 + **그때 쓴 필기 재생**(속도 조절)
- **학생 프로필**: 한 태블릿을 여러 학생이 쓸 때 기록 분리
- **연습장**: 여러 쪽짜리 자유 노트
- **내 문제**: 직접 문제 등록(LaTeX 미리보기) → 문제집·채점·오답노트에 그대로 연동

### 문제은행
- 물리학Ⅰ 35 · 물리학Ⅱ 32 · 지구과학Ⅰ 29 · 수학 36 · 통합과학 20 = **152문제** (그중 89문제는 변형 생성 가능)
- 형식: `assets/problems/*.json` — 스키마는 [docs/problem-schema.md](docs/problem-schema.md)
- 검증: `python3 tools/validate_problems.py` (CI에서도 자동 실행)

## 선생님 실시간 보기

학생이 쓰는 필기가 선생님 PC 브라우저에 실시간으로 그려집니다(0.1초 안팎).

1. 선생님 PC에 [Node.js](https://nodejs.org) 설치
2. 이 저장소를 받은 뒤
   ```bash
   cd server
   npm install
   npm start
   ```
3. 화면에 나온 `학생 앱 서버 주소: ws://192.168.x.x:8080/ws` 를 태블릿 앱 **설정 → 선생님과 실시간 공유**에 입력하고 "연결"
4. PC 브라우저에서 `http://localhost:8080` → 학생별 실시간 필기, 제출 답과 정오, 누적 기록, 메시지 보내기

PC와 태블릿이 **같은 와이파이**여야 합니다. 자세한 내용은 [server/README.md](server/README.md), 프로토콜은 [docs/live-protocol.md](docs/live-protocol.md).

## 개발

- `lib/ink/` 필기 엔진 (입력·렌더링·지우개·올가미·실행취소)
- `lib/core/` 문제 모델, 수식 계산기, 채점기, 변형문제 생성기
- `lib/app/` 상태·기록·저장
- `lib/screens/`, `lib/widgets/` 화면
- `server/` 실시간 서버와 선생님 대시보드

CI(`.github/workflows/android.yml`)가 push마다: 문제 검증 → `flutter analyze` → 테스트 → 화면 스크린샷 렌더링 → APK 빌드 → Releases 게시.
`android/` 폴더는 CI에서 `flutter create`로 만들고 `tools/patch_android.sh`로 앱 설정(이름, 권한, 저지연 S펜 입력, 아이콘)을 적용합니다.

로컬 빌드: Flutter SDK 설치 후 `bash tools/fetch_fonts.sh && flutter create . --platforms android --project-name study_app --org com.une.pulinote && bash tools/patch_android.sh && flutter run`
