# 풀이노트 (study-app)

고1~고3·N수 수험생을 위한 **월구독형 문제 플랫폼 + 학습관리 앱**. 학생은 개념서·유형서·기출·N제·모의고사 문제집을 골라 **내 교재**에 담아 풀고, 매일 오답으로 만든 변형 세트를 받으며, 시험지 위에 S펜으로 직접 풀면 자동 채점됩니다. **학생 계정·선생님 계정**이 나뉘어 있어 선생님은 연결된 학생이 무엇을 틀렸는지 보고, 학생의 질문에 글이나 필기로 답합니다. 문항은 PC 브라우저의 **출제 도구**로 텍스트+수식으로 만들어 앱에 바로 공급해요.

- 1차 대상: **갤럭시탭 S9 Ultra (Android)** — 이후 같은 코드로 iPad 빌드 예정
- 기술: Flutter (앱), Node.js (실시간 서버 + 선생님 웹)

## 설치 (태블릿)

1. 태블릿 브라우저에서 **https://github.com/BruceKalifa/study-app/releases/latest** 를 엽니다.
2. `pulinote.apk` 를 내려받아 실행합니다. 처음이면 "출처를 알 수 없는 앱 설치 허용"을 켜 주세요.
3. 코드를 고칠 때마다 GitHub Actions가 새 APK를 자동으로 만들어 같은 주소에 올립니다. 같은 서명 키를 쓰므로 **덮어서 설치**하면 기록이 유지돼요.

## 기능

### 필기 (굿노트·삼성노트 스타일)
| 동작 | 방법 |
|---|---|
| 쓰기 | S펜 (필압 반영, 저지연 입력) |
| 지우개 | **S펜 옆 버튼을 누른 채 쓰기** → 떼면 원래 펜으로 복귀. 도구막대의 지우개(획/부분)도 있음 |
| 화면 이동 / 확대 | 손가락 한 개로 이동, 두 개로 핀치 확대 (관성 스크롤) |
| 실행 취소 / 다시 실행 | 두 손가락 탭 / 세 손가락 탭 (도구막대 버튼도 있음) |
| 손바닥 인식 방지 | S펜이 닿아 있거나 화면 위에 떠 있으면 손 터치를 무시 |
| 직선 | 선을 긋고 잠깐 멈추면 반듯한 직선으로 변환 |
| 올가미 | 필기를 둘러싸서 선택 → 끌어서 이동, 복제, 색 변경, 삭제 |
| 형광펜 | 반투명, 글씨 아래에 깔림 |
| 종이 | 무지 / 줄 / 모눈 / 점 |

### 계정 (학생 · 선생님)
- 첫 화면에서 **학생 / 선생님**을 고르고 로그인 또는 회원가입 (아이디·비밀번호, 서버 주소). "로그인 없이 써 보기"도 있어요(기록은 그 기기에만)
- **연결**: 선생님 화면에 나오는 6자리 **초대 코드**를 학생이 질문 탭이나 설정에서 입력. 학생 한 명이 여러 선생님(학원·과외)과 연결될 수 있어요
- 학생의 풀이 기록·오답노트·내 교재는 서버에 자동 저장 → **다른 태블릿에서 로그인해도 그대로**
- 자세한 API: [docs/accounts-api.md](docs/accounts-api.md)

### 처음 시작 (온보딩)
- 이름 → 학년(고1~N수) → 목표(수능·내신·둘 다) → **문제집 고르기**(과목 → 개념 → 유형 → 기출 → N제 → 모의고사). 고른 책이 "내 교재"에 담기고 7일 무료 체험으로 시작. 안 골라도 시작할 수 있고, 나중에 "문제집 담기"로 언제든 추가해요.

### 내 교재 (문제를 고르는 방식)
- 앱이 문제를 마음대로 주지 않아요. **학생이 담은 문제집의 문제만** 오늘의 세트·무한 풀기·모의고사 만들기에 쓰여요 (틀린 문제의 쌍둥이·변형은 예외로 오답 세트에 나와요)
- 문제집 카탈로그: 과목별로 커리큘럼 단계(개념·유형·기출·N제·모의고사)와 범위(예: 수학Ⅰ·수학Ⅱ)로 나뉘어요. 문제집 화면에서 미리 보고 "담기", 안 담은 책은 "내 교재에 담고 풀기"
- 출제 도구 → 문제집에서 **커리큘럼 단계·범위·만든 곳**을 정할 수 있어요

### 선생님 화면 (선생님 계정으로 로그인)
- **학생**: 초대 코드, 연결된 학생 카드(오늘·이번 주·전체 문제 수와 정답률, 오답노트에 남은 수, 마지막 풀이)
- **학생 상세**: 틀린 문제(학생이 쓴 답·정답·몇 번 틀렸는지 → 누르면 문제와 해설), 최근 풀이, 과목별 정답률, 학생의 내 교재, 최근 14일 그래프, 그 학생의 질문
- **질문함**: 답을 기다리는 질문 배지. 학생의 풀이 사진 위에 **S펜으로 필기해서 답장**하거나 글(수식 `$…$`)로 답장
- **문제 보기**: 모든 과목·단원 문항 열람

### 선생님께 질문 (학생)
- 문제를 풀다가 오른쪽 위 ❓ 또는 채점 후 "질문" → **지금 풀이 화면(문제+내 필기)이 사진으로 첨부**돼요. 필기로 더 쓰거나 글로 설명 가능
- 질문 탭: 보낸 질문, 답변 대기/완료/해결, 선생님 답이 오면 홈과 탭에 배지

### 문제 풀이와 채점 (모의고사 시험지 형식)
- 한 쪽에 한 문제, 명조체 본문·[배점]·<보 기>·①~⑤. 나머지는 전부 풀이 공간. 기본 **전체화면**(오른쪽 위 버튼으로 끄고 켜기), 아래 **이전·다음** 버튼
- **지문형**(국어·영어): 가로 화면은 왼쪽에 지문, 오른쪽에 문항 / 세로는 지문이 위. "[1~3] 다음 글을 읽고…" 자동 표시
- **표·굵게·밑줄**: 사회 자료, 과학 실험 결과 표, 국어 "밑줄 친 ㉠" 등
- 객관식: 선지를 펜이나 손가락으로 톡 → 선택 (점이 안 찍힘)
- 단답형: 문제 아래 [답] 칸에 손글씨 → **자동 인식**(Google ML Kit, 기기 안) → 다르면 답칸을 손가락으로 톡 눌러 키패드·후보로 수정
- 채점하면 빨간 ○/╱, 해설 시트, 변형·다시 풀기. 해설, 힌트, 북마크, 문제별 풀이 시간

### 구독형 학습 흐름
- **오늘의 오답 변형 세트**(홈): 매일 한 번 만들어져요. 어제 틀린 문제의 **쌍둥이 문항**(출제자가 만든 변형) → 숫자를 바꾼 자동 변형 → 같은 유형의 다른 문항 순서로 고르고, 복습할 날이 된 오답·약점 유형·새 문제로 채웁니다
- **무한 풀기**: 내 교재 전체, 한 권, 과목, 약점 유형 단위로 끝없이. 맞히면 더 어렵게, 틀리면 쉽게
- **내 교재**: 담은 문제집 — 이어 풀기, 틀린 것만 변형으로, 시험처럼 풀기
- **학습관리**: 수능·내신 D-day, 순공 타이머(이번 주 그래프), 오늘 할 일(못 끝낸 일은 다음 날로), 모의고사 등급 추이, 학부모용 주간 리포트 복사
- **구독**: 무료 체험 남은 날, 요금제(예시 가격 — 결제는 출시 때 스토어 정기결제로 연결)

### 기록과 복습 (계속 업데이트됨)
- **오답노트**: 틀린 문제가 자동으로 모이고 1일 → 3일 → 7일 간격으로 다시 나옵니다. 3번 연속 맞히면 "졸업"
- **변형문제**: 숫자·조건을 바꾼 새 문제를 무제한 생성(정답 자동 계산). 틀린 문제를 변형으로 복습
- **통계**: 정답률, 연속 학습일, 최근 14일 그래프, 학습 달력, 과목·단원·난이도별 성취도, 약한 유형
- **풀이 기록**: 모든 제출 기록 + **그때 쓴 필기 재생**(속도 조절)
- **학생 프로필**: 한 태블릿을 여러 학생이 쓸 때 기록 분리
- **연습장**: 여러 쪽짜리 자유 노트
- **내 문제**: 직접 문제 등록(LaTeX 미리보기) → 문제집·채점·오답노트에 그대로 연동

### 문제은행과 출제 도구
- 앱 기본 문항: 국어(독서·문법) · 수학 · 영어 · 통합사회 · 물리학Ⅰ·Ⅱ · 지구과학Ⅰ · 통합과학 · 중2 수학 · 중등 과학 — 원본 197 + 쌍둥이 14, 지문 6, 문제집 13권 (예시 콘텐츠)
- **출제 도구**: 선생님 PC에서 `cd server && npm start` → 브라우저로 `http://<PC IP>:8080/admin` (관리자 키는 서버 화면에 표시). 텍스트+LaTeX로 문항·쌍둥이·지문·문제집을 만들고 시험지 미리보기로 확인
- **앱으로 공급**: 앱 설정 → 서버 주소 입력 → "새 문항 받기". 바뀐 과목만 내려받고, 오프라인에서도 마지막으로 받은 문항을 씁니다
- 형식: `assets/problems/*.json` — 스키마 [docs/problem-schema.md](docs/problem-schema.md), API [docs/content-api.md](docs/content-api.md)
- 검증: `python3 tools/validate_problems.py` (CI에서도 자동 실행)

## 선생님 실시간 보기

학생이 쓰는 필기가 선생님 PC 브라우저에 실시간으로 그려집니다(0.1초 안팎).

1. 선생님 PC에 [Node.js](https://nodejs.org) 설치
2. 이 저장소를 받은 뒤
   ```bash
   cd server
   npm install
   npm start
   ```
3. 화면에 나온 `학생 앱 서버 주소: ws://192.168.x.x:8080/ws` 를 태블릿 앱 **설정 → 선생님과 실시간 공유**에 입력하고 "연결"
4. PC 브라우저에서 `http://localhost:8080` → 학생별 실시간 필기, 제출 답과 정오, 누적 기록, 메시지 보내기

PC와 태블릿이 **같은 와이파이**여야 합니다. 자세한 내용은 [server/README.md](server/README.md), 프로토콜은 [docs/live-protocol.md](docs/live-protocol.md).

## 개발

- `lib/ink/` 필기 엔진 (입력·렌더링·지우개·올가미·실행취소)
- `lib/core/` 문제 모델, 수식 계산기, 채점기, 변형문제 생성기
- `lib/app/` 상태·기록·저장
- `lib/screens/`, `lib/widgets/` 화면
- `server/` 실시간 서버와 선생님 대시보드

CI(`.github/workflows/android.yml`)가 push마다: 문제 검증 → `flutter analyze` → 테스트 → 화면 스크린샷 렌더링 → APK 빌드 → Releases 게시.
`android/` 폴더는 CI에서 `flutter create`로 만들고 `tools/patch_android.sh`로 앱 설정(이름, 권한, 저지연 S펜 입력, 아이콘)을 적용합니다.

로컬 빌드: Flutter SDK 설치 후 `bash tools/fetch_fonts.sh && flutter create . --platforms android --project-name study_app --org com.une.pulinote && bash tools/patch_android.sh && flutter run`
