입력 칸에 커서를 두고 누르면 그 자리에 들어갑니다. 수식 밖이면 $…$ 로 감싸 줍니다. 글자를 선택한 채 누르면 선택한 글자가 첫 칸에 들어갑니다.

규칙
  • 한글은 $ 밖에 쓰기: 속력 $v$ 는
  • \text{} 안에는 영문·단위만: $3\,\text{m/s}$
  • 글자 $ 는 \$
  • \begin{…}, \\ 줄바꿈은 쓸 수 없음
  • 굵게 **…**, 밑줄 __…__, 표는 | 로 시작하는 줄
