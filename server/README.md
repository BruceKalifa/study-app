# Solvit 실시간 서버 · 선생님 화면 · 출제실

학생이 태블릿(Solvit 앱)에 쓰는 필기를 선생님이 브라우저에서 실시간으로 보고,
앱이 풀 **문제를 선생님이 직접 만들어 배포**하는 서버입니다. 서버 하나가 다섯 가지 일을 합니다.

- 학생 앱과 선생님 화면 사이에서 필기를 실시간으로 전달 (`ws://…/ws`)
- 선생님 화면(웹 페이지) 제공 (`http://…/`)
- **출제실**(문제 만들기 웹) 제공 (`http://…/admin`) — 글 + LaTeX 수식으로 문항·지문·문제집 작성
- 앱이 문제를 내려받는 **콘텐츠 API** (`http://…/api/content/…`, 자세한 내용은 `docs/content-api.md`)
- 앱의 **커뮤니티 게시판**과 **공부시간 순위** (`http://…/api/community/…`, `/api/ranking`, 자세한 내용은 `docs/community-api.md`)

학생별 제출 기록(최근 200개)과 통계는 `server/data/records.json` 에 저장되어, 서버를 껐다 켜도 남아 있습니다.
필기 자체는 저장하지 않고, 학생이 지금 보고 있는 페이지의 필기만 메모리에 들고 있습니다.

## 1. 선생님 컴퓨터에서 실행하기

### 준비 (처음 한 번)

1. **Node.js 설치** — <https://nodejs.org> 에서 LTS 버전(18 이상)을 내려받아 설치합니다.
   설치 후 터미널(Windows 는 "명령 프롬프트" 또는 "PowerShell")에서 `node -v` 를 입력해 버전이 나오면 됩니다.
2. 터미널에서 이 폴더로 이동한 뒤 필요한 패키지를 설치합니다.

   ```bash
   cd study-app/server
   npm install
   ```

### 서버 켜기

```bash
npm start
```

켜지면 아래처럼 주소가 표시됩니다.

```
────────────────────────────────────────────────────
 Solvit 실시간 서버가 켜졌습니다 (포트 8080)
────────────────────────────────────────────────────
 선생님 화면 주소:   http://192.168.0.12:8080/
 문제 출제 도구:     http://192.168.0.12:8080/admin
 학생 앱 서버 주소:  ws://192.168.0.12:8080/ws
 …
────────────────────────────────────────────────────
 ★ 출제 도구 관리자 키:  482913
```

- **선생님 화면**: 이 컴퓨터의 브라우저에서 `http://localhost:8080/` 을 엽니다. (같은 Wi-Fi 의 다른 기기에서는 표시된 `http://192.168…` 주소)
- **학생 앱**: 태블릿의 Solvit 앱 → 설정 → 서버 주소에 표시된 `ws://192.168.0.12:8080/ws` 를 입력합니다.
  학생이 아무도 접속하지 않았을 때는 선생님 화면에도 이 주소가 크게 표시되고, 복사 버튼이 있습니다.
- 끄려면 터미널에서 `Ctrl + C` 를 누릅니다. 끄기 직전에 기록이 저장됩니다.
- 포트를 바꾸려면 `PORT=9000 npm start` (Windows PowerShell 은 `$env:PORT=9000; npm start`).

> 주소(192.168.x.x)는 공유기가 정해 주는 값이라 날마다 바뀔 수 있습니다. 서버를 켤 때마다 표시되는 주소를 확인하세요.
> 자주 바뀌어 불편하면 공유기 설정에서 이 컴퓨터에 "고정 IP(DHCP 예약)"를 지정하면 됩니다.

### 꼭 확인할 것

- **같은 Wi-Fi**: 학생 태블릿과 선생님 컴퓨터가 **같은 공유기(같은 Wi-Fi)** 에 연결되어 있어야 합니다.
  게스트 Wi-Fi 나 "AP 격리(클라이언트 격리)"가 켜진 Wi-Fi 에서는 기기끼리 통신이 막혀 접속되지 않습니다.
- **Windows 방화벽**: 처음 `npm start` 를 하면 "Windows 보안 경고 — Node.js 의 네트워크 액세스 허용" 창이 뜹니다.
  **개인 네트워크**에 체크하고 "액세스 허용"을 누르세요.
  이미 "취소"를 눌렀다면: 제어판 → Windows Defender 방화벽 → "앱이 방화벽을 통과하도록 허용" → Node.js 의 "개인" 체크.
  (그래도 안 되면 Wi-Fi 연결 속성에서 네트워크 프로필이 "공용"이 아니라 "개인"인지 확인하세요.)
- **macOS**: "들어오는 네트워크 연결을 허용하겠습니까?" 창이 뜨면 "허용"을 누릅니다.
- **인터넷**: 선생님 화면의 글꼴(Pretendard)과 수식 표시(KaTeX)는 인터넷(CDN)에서 불러옵니다.
  인터넷이 없어도 필기 보기는 그대로 되지만, 수식이 `$x^2$` 같은 원문으로 보이고 기본 글꼴로 표시됩니다.
  출제실 미리보기의 시험지 글꼴(나눔명조)과 수식도 마찬가지로 인터넷에서 불러옵니다(인터넷이 없어도 편집·저장은 됩니다).

## 2. 태블릿 없이 미리 보기 (시뮬레이터)

서버를 켠 상태에서 다른 터미널을 하나 더 열고:

```bash
npm run sim
```

가짜 학생 3명(김민준, 이서연, 박지호)이 접속해 숫자와 포물선 그래프를 쓰고, 형광펜·지우개를 쓰고, 답을 제출합니다.
선생님 화면에서 실시간으로 필기가 나타나는지 확인할 수 있습니다.

```bash
node tools/sim-student.js --forever            # 계속 반복 (Ctrl + C 로 종료)
node tools/sim-student.js ws://192.168.0.12:8080/ws --count 2 --speed 2
```

> 시뮬레이터 학생도 기록에 남습니다. 지우려면 서버를 끄고 `data/records.json` 을 삭제하세요.

자동 점검: 서버를 켠 상태에서 `npm test` 를 실행하면 선생님·학생 역할의 테스트 클라이언트가 접속해
snapshot, 실시간 획 중계, 메시지 전달, records.json 저장 등을 확인합니다. (테스트 학생 "테스트봇"이 기록에 남습니다.)

## 3. 선생님 화면 사용법

- **실시간 탭**: 접속 중이거나 오늘 접속했던 학생이 종이 모양 칸으로 보입니다.
  칸마다 이름, 접속 상태(초록 점), 지금 푸는 문제, 마지막 제출 결과(정답/오답과 제출한 답)가 표시되고,
  학생이 쓰는 중이면 종이 테두리가 파랗게 표시됩니다. 필기가 아래로 내려가면 화면이 자동으로 따라갑니다.
- **칸을 누르면** 크게 볼 수 있습니다. 왼쪽에 문제(수식 포함)와 선택지, 오른쪽에 큰 필기 화면이 나옵니다.
  마우스 휠이나 드래그로 페이지를 위아래로 볼 수 있고, "최신 필기 따라가기"를 다시 누르면 학생이 쓰는 위치로 돌아갑니다.
  아래 "메시지 보내기"로 그 학생 화면에 알림을 보낼 수 있습니다. (Esc 로 닫기)
- **전체에게 메시지**: 접속한 모든 학생에게 알림을 보냅니다.
- **기록 탭**: 학생별 푼 문제 수, 정답률, 연속 정답, 오늘 푼 수, 약한 단원, 마지막 제출 시각.
  제목 줄을 누르면 정렬, 학생 줄을 누르면 최근 제출(문제, 제출한 답, 정답/오답, 걸린 시간, 제출 시각)이 펼쳐집니다.
- 서버가 꺼지거나 Wi-Fi 가 끊기면 화면 위에 "연결 끊김"이 표시되고, 다시 켜지면 자동으로 다시 연결됩니다.

## 4. 출제실 — 문제 만들기 (`/admin`)

앱에서 학생이 푸는 문제를 선생님이 **글 + LaTeX 수식**으로 직접 만들고 고치는 웹 도구입니다.
그림 파일 없이 글로 쓰므로 고치기 쉽고, 앱 화면 크기에 맞춰 자동으로 줄바꿈됩니다.

### 열기

1. 서버를 켭니다(`npm start`). 검은 창에 **`★ 출제 도구 관리자 키: 482913`** 같은 6자리 키가 표시됩니다.
   - 키는 처음 켤 때 한 번 만들어 `server/data/admin-key.txt` 에 저장되므로 다음에 켜도 같습니다.
   - 키를 바꾸려면 이 파일을 지우고 다시 켜거나, `ADMIN_KEY=원하는키 npm start` (PowerShell: `$env:ADMIN_KEY="원하는키"; npm start`).
2. 브라우저에서 **`http://<선생님 PC 주소>:8080/admin`** 을 엽니다. (이 컴퓨터에서는 `http://localhost:8080/admin`)
   PC 주소는 서버 창의 "문제 출제 도구:" 줄에 나옵니다. 같은 Wi-Fi 의 노트북·태블릿 브라우저에서도 열 수 있습니다.
3. 처음 열면 관리자 키를 묻습니다. 한 번 입력하면 그 브라우저에 기억됩니다(오른쪽 위 🔑 로 다시 입력).
   **키는 학생에게 알려 주지 마세요.** 키를 아는 사람은 문제를 고치거나 지울 수 있습니다.

### 화면 구성

- **왼쪽 — 과목**: 국어·수학·영어·사회·과학으로 묶여 문항 수와 함께 보입니다. `+ 과목` 으로 새 과목,
  아래 `과목 정보 · 대단원 순서` 로 이름·id·색·교과군·학교급·대상 학년(중1~N수)·트랙·**대단원 순서**를 고칩니다.
- **가운데 — 목록**: 검색, 대단원·유형·난이도·형식·쌍둥이 필터. 쌍둥이 문항은 원본 아래에 들여 쓰여 보입니다.
  - `+ 새 문항` · `쌍둥이 만들기`(고른 문항을 복사해 `원본id-t1` 로, 원본을 지정해 줌) · `복제` · `삭제`
  - 목록을 누른 뒤 ↑↓ 키로 이동할 수 있습니다.
- **오른쪽 — 편집 + 미리보기**: 왼쪽에 입력 칸, 오른쪽에 **시험지 모양 미리보기**(나눔명조, 문항 번호, [배점], 〈보 기〉 상자, ①~⑤, 단답형 답 칸)와
  정답·해설 미리보기가 입력하는 대로 바로 바뀝니다. 자동 변형(template)이 있으면 `변형 예시` 로 숫자가 바뀐 문제를 볼 수 있습니다.
- 위쪽 탭: **문항 · 지문 · 문제집**
  - **지문**: 국어·영어처럼 한 지문에 여러 문항이 딸릴 때. 지문을 만들고 문항 편집의 "지문" 칸에서 연결합니다. 이 지문을 쓰는 문항이 함께 보입니다.
  - **문제집**: 제목·과목·수준(기본/실전/심화/모의고사)·설명, 문항 추가(검색·대단원 필터, `+ 추가` 또는 끌어 놓기), 끌어서 순서 바꾸기·↑↓·삭제.
    문제집은 여러 개를 고친 뒤 **`문제집 저장`** 을 눌러야 서버에 반영됩니다.
- **저장**: `저장` 버튼 또는 **Ctrl + S**. 저장하지 않은 변경이 있으면 위쪽에 주황색 "저장 안 됨"이 보이고, 다른 문항으로 갈 때 물어봅니다.
- **오류 표시**: 입력하는 동안 바로 검사해 칸 아래와 편집 영역 위에 빨간색(저장 불가)·노란색(주의)으로 보여 줍니다.
  저장할 때 서버가 한 번 더 검사하고(다른 과목과 id 가 겹치는지 등), 오류가 있으면 저장하지 않고 이유를 보여 줍니다. 오류를 누르면 그 칸으로 이동합니다.
- **가져오기 · 내보내기**: 과목 JSON·문제집 JSON·전체 백업을 가져오면 **id 기준으로 합칩니다**(같은 id 는 덮어씀).
  `전체 백업 내보내기` 를 가끔 눌러 파일로 보관해 두세요.
- **∑ LaTeX 도움말** (Ctrl + /): 분수·루트·지수·벡터·단위(`\text{m/s}`)·그리스 문자 등을 누르면 커서 자리에 들어갑니다.
  수식 밖에서 누르면 `$…$` 로 감싸 주고, 글자를 선택한 채 누르면 선택한 글자가 첫 칸에 들어갑니다.

### 쓰는 요령

- 수식은 `$…$` 안에만: `속력 $v=3\,\text{m/s}$ 로 운동한다.` — **한글은 `$` 밖에** 씁니다(`$3\text{초}$` ✗ → `$3$ 초` ✓).
- 단위는 `\,\text{m/s}` (숫자와 단위 사이 `\,` 는 작은 띄어쓰기). 각도 `30^\circ`, 벡터 `\vec{F}`, 분수 `\frac{1}{2}`.
- 굵게 `**…**`, 밑줄 `__…__`(국어 "밑줄 친 ㉠"), 글자 그대로의 `$` 는 `\$`.
- 표: `|` 로 시작하는 줄. 둘째 줄을 `|---|---|` 로 쓰면 첫 줄이 머리글이 됩니다. 모든 줄의 칸 수를 맞추세요.
- 〈보기〉: `+ 보기 항목` 은 `ㄱ. ` `ㄴ. ` 을 붙여 줍니다. 국어·사회처럼 글·표로 된 〈보기〉는 `+ 자유 형식 <보기>`.
  항목이 2~4개면 `선택지에 ㄱ·ㄴ·ㄷ 조합 넣기` 로 ①ㄱ ②ㄴ ③ㄱ,ㄷ … 을 한 번에 채웁니다.
- **유형(topic)** 은 약점 분석과 오답 변형의 기준입니다. 같은 유형은 목록에서 골라 **같은 이름**으로 쓰세요.
- 단답형 정답은 숫자·분수(`12`, `-3/2`, `2.5`)만, 단위는 "단위" 칸에. 소수 답이면 "허용 오차"를 넣을 수 있습니다.
- **쌍둥이**는 틀린 문제의 "매일 오답 변형 세트"에 나옵니다. 원본에서 `쌍둥이 만들기` → 숫자·조건만 바꿔 저장하면 됩니다.
  쌍둥이는 문제집에 넣을 수 없고, 쌍둥이의 쌍둥이도 만들 수 없습니다(항상 원본을 가리킴).
- 자동 변형(template)은 JSON 으로 씁니다. `예시 틀 넣기` 를 눌러 고쳐 쓰고 `변형 예시` 로 확인하세요. 문법: `docs/problem-schema.md`.

### 앱이 문제를 받는 방법

학생 앱은 **설정에 입력한 서버 주소**(위의 `ws://192.168.0.12:8080/ws`)와 같은 서버에서 문제를 내려받습니다.
출제실에서 저장하면 그 과목의 버전이 바뀌고, 앱은 다음에 문제 목록을 새로 고칠 때 바뀐 과목만 다시 받습니다.
서버에 연결할 수 없을 때는 마지막으로 받은 문제(처음이면 앱에 들어 있는 기본 문제)를 씁니다.

### 문제 파일

- 문제는 `server/content/` 폴더에 과목마다 JSON 파일 하나(`phy1.json` …)와 `workbooks.json` 으로 저장됩니다. 형식은 `docs/problem-schema.md` 와 같습니다.
- 처음 켤 때 이 폴더가 비어 있으면 앱의 기본 문제(`assets/problems/`)를 복사해 시작합니다. 이후에는 다시 복사하지 않습니다.
- 삭제한 과목 파일은 `server/content/_trash/` 로 옮겨 둡니다.
- 다른 폴더를 쓰려면 `CONTENT_DIR=경로 npm start`.

## 5. 커뮤니티와 공부시간 순위

학생 앱의 **커뮤니티**(자유·질문·공부인증·입시정보·고민·멘탈 게시판)와 **공부시간 순위**도 이 서버가 맡습니다.
앱은 문제를 받는 서버 주소와 같은 주소를 씁니다. 따로 켤 것은 없습니다.

- **저장 위치**: `server/data/community.json`(글·댓글·좋아요·신고), `server/data/ranking.json`(날짜별 공부시간).
  다른 폴더를 쓰려면 `DATA_DIR=경로 npm start`. 파일은 임시 파일에 쓴 뒤 바꿔 끼우므로 쓰는 도중 꺼져도 깨지지 않습니다.
  공부시간 기록은 **90일**이 지나면 자동으로 지웁니다.
- **도배 방지**: 같은 학생은 20초에 글 1개, 5초에 댓글 1개까지 쓸 수 있습니다.
- **신고와 숨김**: 서로 다른 학생 **3명**이 신고하면 글이 자동으로 숨겨집니다(같은 학생의 중복 신고는 한 번만 셉니다).
- **관리 — 출제실의 `커뮤니티 관리` 탭** (`/admin` 위쪽 탭, 관리자 키 필요):
  - 왼쪽 **신고된 글**: 숨겨진 글과 신고가 들어온 글, 신고 사유와 시각. `복구`(숨김을 풀고 신고 기록을 지움) · `삭제`.
  - 오른쪽 **최근 글**: 숨긴 글까지 모두 최신 순으로. 검색, `댓글` 펼쳐서 댓글 하나씩 삭제, 글 `삭제`. 삭제는 되돌릴 수 없습니다.
- **개인정보 보호**
  - 순위에 쓰는 이름은 **저장할 때부터 가립니다**: 첫 글자 + `XX` (`오예진` → `오XX`, `Kim` → `KXX`, 이름이 없으면 `익명`). 전체 이름은 서버에 남지 않습니다.
  - 앱이 학생을 구분하는 `userId`(앱이 무작위로 만든 값)는 서버 파일에만 있고, **어떤 응답에도 내보내지 않습니다**.
    본인 글인지는 `mine`, 좋아요를 눌렀는지는 `liked` 로만 알려 줍니다. 관리 화면에도 보이지 않습니다.
  - 글·댓글에는 학생이 정한 닉네임과 학년만 보입니다.

## 6. (선택) 인터넷 서버에 올리기

학원 밖(집 등)에서도 쓰고 싶다면 WebSocket 을 지원하는 호스팅에 올리면 됩니다.
예: **Render**(Web Service), **Railway**, **Fly.io** 등.

- 이 `server/` 폴더를 올리고 시작 명령을 `npm start` 로 지정합니다. 포트는 호스팅이 주는 `PORT` 환경변수를 자동으로 씁니다.
- 주소는 `https://…` 가 되므로 학생 앱에는 **`wss://<내 주소>/ws`** 를 입력합니다. (`ws://` 가 아니라 `wss://`)
  선생님 화면은 `https://<내 주소>/` 로 열면 자동으로 `wss://` 로 연결합니다.
- 무료 요금제는 한동안 접속이 없으면 서버가 잠들거나, 재시작 시 디스크가 초기화되어 `data/records.json` 이 지워질 수 있습니다.
  기록(커뮤니티 글·순위 포함)을 계속 남기려면 영구 디스크(볼륨)를 붙이고 `DATA_DIR` 환경변수로 그 경로를 지정하세요.
  **만든 문제(`content/`)도 같은 이유로 지워질 수 있으니** `CONTENT_DIR` 도 영구 디스크로 지정하고, `ADMIN_KEY` 를 긴 값으로 정하세요.
- 선생님 화면(실시간 필기)에는 로그인 기능이 없습니다. 인터넷에 공개하면 주소를 아는 누구나 선생님 화면을 볼 수 있으니, 주소를 외부에 공유하지 마세요.
  출제실과 관리 API 는 관리자 키가 있어야 쓸 수 있지만, 문제 내려받기(`/api/content/…`)는 키 없이 열려 있습니다.

## 7. 참고 (개발자용)

- 프로토콜: `docs/live-protocol.md`. 필드 이름은 그대로 지키고, 아래 필드만 **추가**했습니다.
  - 서버 → 학생: `welcome { studentId, serverTime }` (hello 직후), `error { reason }` (`bad_json`, `hello_required`, `studentId_required`, `bad_message`, …)
  - 서버 → 선생님: `answer`·`stats`·`page` 에 `at`(서버 수신 시각, ms), `answer` 에 `title`/`topic`(현재 페이지와 같은 문제일 때),
    `student_online` 에 `device`, `snapshot` 의 각 학생에 `lastSeen`, `snapshot.serverTime`
  - 선생님 → 서버: `message` 에 선택 `clientId`, 응답 `message_ack { ok, delivered, studentId, clientId }`; `snapshot_request`(전체 상태 다시 받기); `ping` → `pong`
  - 학생 → 서버 `page` 의 선택 필드 `boxItems`(〈보기〉 항목), `topic`, `unit`, `subject` 를 보내면 선생님 화면에 표시
  - `ping` 은 선생님에게 중계하지 않음. 모르는 `type` 은 `studentId` 를 붙여 그대로 중계
- 제한: 메시지 1개 최대 2MB(넘으면 연결 종료 1009), 페이지당 최근 5000획, 획당 20000점, 선생님 메시지 500자.
- 같은 `studentId` 로 다시 접속하면 예전 연결을 코드 `4000`(replaced)으로 닫고 새 연결로 바꿉니다. 이때는 `student_offline` 을 보내지 않습니다.
- 30초마다 WebSocket ping 으로 끊긴 연결을 정리합니다.
- 환경변수: `PORT`(기본 8080), `HOST`(기본 0.0.0.0), `DATA_DIR`(기본 `server/data`),
  `CONTENT_DIR`(기본 `server/content`), `SEED_DIR`(기본 `assets/problems`), `ADMIN_KEY`(없으면 `data/admin-key.txt`).
- 기타 주소: `GET /api/info`(학생 앱용 주소 목록, `adminUrls` 추가), `GET /healthz`.
- 콘텐츠 API·관리 API·검증 규칙: `docs/content-api.md`. 코드: `content-store.js`(저장·직렬화·원자적 쓰기),
  `content-api.js`(라우팅·검증), `public/admin/schema.js`(검증·표기법 파서·식 계산기 — 서버와 출제 웹이 같은 파일을 씀),
  `public/admin/`(출제 웹, 빌드 없음).
- 커뮤니티·순위 API: `docs/community-api.md`. 코드: `community.js`(게시판·신고·관리 API), `ranking.js`(순위·이름 가리기),
  `json-store.js`(직렬화된 원자적 JSON 저장), `http-util.js`(공용 HTTP 도우미). 관리 API 는 콘텐츠 API 와 같은 관리자 키를 씁니다.
- 테스트:
  - `npm run test:content` — 임시 폴더로 서버를 직접 띄워 콘텐츠 API 전체를 확인합니다(서버를 켜 둘 필요 없음, 기본 문제·기록은 건드리지 않음).
  - `npm run test:community` — 임시 폴더로 서버를 직접 띄워 커뮤니티·순위 API(검증, 도배 방지, 신고·숨김, 관리, 이름 가리기, userId 비노출, 재시작 후 유지)를 확인합니다.
  - `npm test` (= `npm run test:live`) — 켜 둔 서버(localhost:8080)에 접속해 실시간 기능을 확인합니다.
